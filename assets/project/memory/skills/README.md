# Procedural Memory

Store only verified practices that are likely to be reused. Each Markdown entry describes its purpose, preconditions, steps, success evidence, failure handling, scope, and sources.

This directory holds project knowledge; it is not an auto-discovered Codex skill location. To publish a skill, create and validate a separate `SKILL.md` according to the target tool's skill format. Avoid maintaining duplicate copies of the same content.
