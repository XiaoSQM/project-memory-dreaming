## 原资料与实现选择的区别

`org/team/agents/skills` 分层、progress 只追加、固定评测集及人工审核流程来自用户指南的个人项目做法。Python 工具、UUID、隔离批次格式、审核哈希冻结、拒绝删除文件、增量处理及回滚保护是本技能为可重复执行所作的工程选择。

同一工作区中“每个 Agent 改完就 commit”不能防止另一个写入者在提交前覆盖文件。本实现要求遵守同一协作锁，再进行内容哈希核对；Git 仅用于可选历史。协作约定也不等同于 OS 权限控制。

“至少两个独立会话才提炼为规则”和“个人项目每周整理一次”是可调整的本地默认值，不是视频给出的普遍定律。视频约 14 分钟的 97% / 30% 出现在记忆系统客户引言页，不能归为 Dreaming 单独效果，也不能作为本技能的效果保证。

字幕、完整视频与逐字稿仅用于研究核对，不随技能包重新分发。
